# Архив задач по физике

Два хранилища [Obsidian](https://obsidian.md) с задачами по физике. Каждое — самостоятельная папка: заметки, рисунки и
исходные PDF лежат внутри, ссылки работают без интернета.

| Папка | Что внутри | Объём |
|---|---|---|
| `olympiads/` | Олимпиадные задачи: BelPhO, IEPhO, IZhO, NbPhO, RomPhO, RusPhO, Туймаада | 3018 задач, 878 PDF |
| `igcse/` | Cambridge IGCSE Physics 0625, экзаменационные работы 2002–2025 (вместе с вариантами 1524) | 11 918 вопросов из 700 работ, 1625 PDF |

## Как открыть

1. Установите Obsidian (бесплатно, Windows / macOS / Linux).
2. «Open folder as vault» → выберите папку `olympiads` или `igcse` (не корень архива — это два отдельных хранилища).
3. Начните с заметки `Главная.md`.

Формулы набраны в LaTeX и отображаются встроенным KaTeX Obsidian; рисунки — SVG/PNG из папки `_figures`, оригиналы
работ — в `_pdf` (из каждой заметки есть ссылка на нужную страницу PDF).

## Устройство хранилищ

**`olympiads/`**
- `Задачи/<олимпиада>/<год>/<этап>/` — заметка = задача: условие, ответ и решение (где есть), ссылки на PDF;
- `Олимпиады/` — страницы олимпиад со списками по годам и этапам;
- `Темы/` — задачи по разделам физики.

**`igcse/`**
- `Задачи/<год>/<сессия>/Paper NN/` — заметка = вопрос: условие, ответ (для тестов), схема оценивания и фрагмент отчёта
  экзаменаторов в свёрнутых блоках, ссылки на страницы PDF; в свойствах заметки — темы программы 0625, уровень
  Core/Extended, баллы;
- `Работы/` — карточки работ (все вопросы работы и сопутствующие PDF);
- `Темы/` — вопросы по темам программы Cambridge 0625 (разделы 1–6, плюс практические навыки и темы старых программ).

Свойства заметок (год, олимпиада, тема, уровень и т. п.) можно фильтровать встроенным поиском Obsidian или плагином Bases / Dataview.

## Источники

Условия, решения и схемы оценивания — из официальных публикаций олимпиад и Cambridge International (PDF в папках `_pdf`).
Текст извлечён из этих PDF и проверен по оригиналам; в IGCSE ошибки и расхождения самих PDF Cambridge отмечены в свойстве
заметки `flags`.
