> [!abstract] Кратко (составлено моделью)
> Сравнить полезную мощность подъёма по времени выполнения одинаковой работы.

A child runs up a set of stairs four times. The time taken for each run is recorded.

Which time is measured when the child’s useful power is greatest?

**A** 10 s  
**B** 20 s  
**C** 30 s  
**D** 40 s

> [!answer]- Ответ
> **A**

> [!report]- Отчёт экзаменаторов
> Most candidates successfully made the link between the child having greatest power when work is done in the shortest time.
