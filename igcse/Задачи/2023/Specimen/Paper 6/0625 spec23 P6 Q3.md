> [!abstract] Кратко (составлено моделью)
> Определить увеличение изображения линзы по измерениям, построить график и предложить улучшение измерительной установки.

A student investigates the magnification produced by a converging lens.

He is using the apparatus shown in Fig. 3.1.

![[0625-y23-6-p9-f1.svg]]

**Fig. 3.1**

**(a)** The illuminated object consists of a triangular-shaped hole in a piece of card. Fig. 3.2 shows, full size, the illuminated object.

![[0625-y23-6-p9-f2.svg]]

**Fig. 3.2**

Measure and record the height *h*$_{\text{O}}$ of the triangular-shaped hole.

*h*$_{\text{O}}$ = \_\_\_\_\_\_ cm **[1]**

**(b)** The distance between the illuminated object and the centre of the lens is set to *u* = 20.0 cm. The screen is moved until a focused image of the illuminated object is seen, as shown in Fig. 3.3.

![[0625-y23-6-p10-f1.svg]]

**Fig. 3.3**

The student repeats the procedure for *u* = 30.0 cm, *u* = 40.0 cm, *u* = 50.0 cm and *u* = 60.0 cm. His results are shown in Table 3.1.

Measure, and record in the first row of Table 3.1, the height *h*$_{\text{I}}$ of the image.

Using your results from **(a)** and the equation $M = \dfrac{h_{\text{O}}}{h_{\text{I}}}$, calculate a value *M* and record this value in Table 3.1.

**Table 3.1**

| *u* / cm | *h*$_{\text{I}}$ / cm | *M* |
|---|---|---|
| 20.0 |  |  |
| 30.0 | 1.5 | 0.93 |
| 40.0 | 0.9 | 1.6 |
| 50.0 | 0.6 | 2.3 |
| 60.0 | 0.5 | 2.8 |

**[2]**

**(c)** Plot a graph of *u* / cm (*y*-axis) against *M* (*x*-axis).

You do **not** have to start your axes at the origin (0, 0).

![[0625-y23-6-p11-f1.svg]]

**[4]**

**(d)** Determine the gradient *G* of the graph.

Show clearly on the graph how you obtained the necessary information.

*G* = \_\_\_\_\_\_ **[2]**

**(e)** Describe **one** difficulty that might be experienced when measuring the height of the image *h*$_{\text{I}}$.

Suggest an improvement to the **apparatus** to reduce this difficulty.

difficulty  \_\_\_\_\_\_

improvement  \_\_\_\_\_\_ **[2]**
