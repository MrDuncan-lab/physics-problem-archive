> Определить, через какие лампы проходит ток в предложенной схеме.

X, Y and Z are lamps.

![[0625-m23-12-p12-f1.svg]]

In which lamps is there a current?

|  | X | Y | Z |
|---|---|---|---|
| **A** | ✓ | ✗ | ✓ |
| **B** | ✓ | ✗ | ✗ |
| **C** | ✗ | ✓ | ✓ |
| **D** | ✗ | ✓ | ✗ |

key: ✓ = current in lamp, ✗ = no current in lamp

> [!answer]- Ответ
> **C**
