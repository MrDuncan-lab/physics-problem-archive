> Определение массы груза из равновесия метровой линейки.

The IGCSE class is determining the mass of a load using a balancing method.

Fig. 1.1 shows the apparatus.

![[0625-s10-62-p2-f1.svg]]

**Fig. 1.1**

The load **X** has been taped to the metre rule so that its centre is exactly over the 90.0 cm mark. It is not moved during the experiment. A mass *m* of 40 g is placed on the rule and its position adjusted so that the rule is as near as possible to being balanced with the 50.0 cm mark exactly over the pivot. This is repeated using a range of masses. The readings are shown in Table 1.1

**Table 1.1**

| *m* /g | *d* /cm | 1 1 *d* / cm |
|---|---|---|
| 40 | 30.2 |  |
| 50 | 23.9 |  |
| 60 | 20.0 |  |
| 70 | 17.1 |  |
| 80 | 15.1 |  |

**(a)** For each value of *d*, calculate 1/*d* and record it in the table. **[2]**

![[0625-s10-62-p3-f1.svg]]

**(b)** Plot a graph of *m* /g (*y*-axis) against 1 (*x*-axis). **[4]**

**(c)** Determine the gradient *G* of the graph. Show clearly on the graph how you obtained the necessary information.

*G* =  \_\_\_\_\_\_ **[2]**

**(d)** Determine the mass μ of the load **X** using the equation μ = *G/k* where *k* = 40.0 cm.

μ =  \_\_\_\_\_\_ **[2]**

> [!report]- Отчёт экзаменаторов
> **(a)** Most correctly calculated the 1/d values but rounding errors and inconsistent significant figures lost marks. In particular, there was a reluctance to express the 0.0500 value to more than one significant figure.
>
> 32 © UCLES 2010
>
> **(b)** Many graphs were drawn well with clear, accurate plots and fine, well-judged lines. The main error was in the choice of scale. Without a ‘false zero’, the plots generally took up less than half of the grid.
>
> **(c)** Whilst there was some indication that the ‘triangle method’ had been used, the chosen points were often too close together – indicating poor experimental practice. Some good, clear responses were seen but a significant number of candidates ignored the instruction to show clearly on the graph how information had been obtained.
>
> **(d)** Totally correct answers were not common, those within the range frequently being spoiled by excessive significant figures or an inappropriate unit.
