# Question 15 (1 mark)

**IGCSE 0625 Physics** · May/June 2024 · Paper 1 — Multiple Choice (Core), вариант 2 · вопрос 15  
Источник: [[_pdf/2024/0625_s24_qp_12.pdf#page=6|условие, стр. 6]] · [[_pdf/2024/0625_s24_ms_12.pdf|схема оценивания]] · [[_pdf/2024/0625_s24_er.pdf#page=3|отчёт экзаменаторов]]  
Работа: [[0625 s24 P12]]  
Темы: [[2.3.3 Radiation]]

> [!abstract] Кратко (составлено моделью)
> Определить среды, через которые может распространяться тепловое излучение.

Thermal radiation is emitted from all objects.

Which mediums can thermal radiation travel through?

|  | glass | water | air | vacuum |
|---|---|---|---|---|
| **A** | ✓ | ✓ | ✓ | ✓ |
| **B** | ✓ | ✓ | ✓ | ✗ |
| **C** | ✗ | ✓ | ✓ | ✓ |
| **D** | ✗ | ✗ | ✗ | ✓ |

key: ✓ = can travel through this medium, ✗ = cannot travel through this medium

> [!answer]- Ответ
> **A**

> [!report]- Отчёт экзаменаторов
> Although many stronger candidates answered this correctly, a significant number of other candidates incorrectly thought that thermal radiation cannot travel through a vacuum and therefore chose option **B**.
