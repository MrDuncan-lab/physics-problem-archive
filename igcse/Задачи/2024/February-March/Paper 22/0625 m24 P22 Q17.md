Источник: [[_pdf/2024/0625_m24_qp_22.pdf#page=8|условие, стр. 8]] · [[_pdf/2024/0625_m24_ms_22.pdf|схема оценивания]] · [[_pdf/2024/0625_m24_er.pdf#page=3|отчёт экзаменаторов]]

> [!abstract] Кратко (составлено моделью)
> Определить характер и размер изображения в плоском зеркале.

Which row describes some characteristics of an image formed in a plane mirror?

|  | image type | image size |
|---|---|---|
| **A** | real | diminished |
| **B** | real | same size as the object |
| **C** | virtual | diminished |
| **D** | virtual | same size as the object |

> [!answer]- Ответ
> **D**

> [!report]- Отчёт экзаменаторов
> Some weaker candidates selected option **B**, believing the image in a plane mirror to be real.
