protons, neutrons and electrons.

**(i)** are found in an -particle,

number of protons =  \_\_\_\_\_\_

number of neutrons =  \_\_\_\_\_\_

number of electrons =  \_\_\_\_\_\_ **[1]**

**(ii)** are found in a -particle?

number of protons =  \_\_\_\_\_\_

number of neutrons =  \_\_\_\_\_\_

number of electrons =  \_\_\_\_\_\_ **[1]**

**(b)** Sodium-24 can be represented as$^{24}_{11}$Na.

How many of each of these particles are there in a neutral atom of$^{24}_{11}$Na?

number of protons =  \_\_\_\_\_\_

number of neutrons =  \_\_\_\_\_\_

number of electrons =  \_\_\_\_\_\_ **[3]**

**(c)** A nucleus of sodium-24 decays to become magnesium-24, by the emission of one particle. The equation below describes this change.

The symbol$_{\text{y}}^{\text{x}}$ represents the emitted particle.

$^{24}_{11}$Na $^{24}_{12}$Mg + $_{\text{y}}^{\text{x}}$

**(i)** State the value of x \_\_\_\_\_\_ **[1]**

**(ii)** State the value of y \_\_\_\_\_\_ **[1]**

**(iii)** What type of particle is ?  \_\_\_\_\_\_ **[1]**

> [!report]- Отчёт экзаменаторов
> The responses to this question were either very good or very bad. It would seem that some Centres fail to spend sufficient time on this section of the syllabus. An enormous number of candidates believe that alpha and beta particles contain hundreds of protons, neutrons and electrons, and very few could cope with the equation of part **(c)**. Interestingly though, there seemed to be an ability to answer (b) at least partly correctly.
