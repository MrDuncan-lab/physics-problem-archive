Uranium-235 can undergo nuclear fission in many ways.

Which equation correctly shows a possible fission reaction for uranium-235?

1 235 141 92 1

**A** n + U → Ba + Kr + 3 n

0 92 56 36 0

1 235 91 144 1

**B** n + U → Sr + Xe + 2 n

0 92 38 54 0

1 235 95 136 1

**C** n + U → Rb + Cs + 3 n

0 92 37 55 0

1 235 87 146 1

**D** n + U → Br + La + 4 n

0 92 35 57 0

> [!answer]- Ответ
