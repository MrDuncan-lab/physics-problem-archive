# Question 28 (1 mark)

**IGCSE 0625 Physics** · May/June 2020 · Paper 1 — Multiple Choice (Core), вариант 3 · вопрос 28  
Источник: [[_pdf/2020/0625_s20_qp_13.pdf#page=13|условие, стр. 13]] · [[_pdf/2020/0625_s20_ms_13.pdf|схема оценивания]]

Темы: [[4.1 Simple phenomena of magnetism]]

> [!abstract] Кратко (составлено моделью)
> Выбирают гвоздь с наибольшей остаточной магнитной силой по экспериментальным данным.

Four nails **A**, **B**, **C** and **D** are tested to find which makes the strongest permanent magnet.

One of the nails is placed against a bar magnet and the number of paper clips which the nail can support is recorded.

![[0625-s20-13-p13-f1.svg]]

The bar magnet is then removed and the number of paper clips remaining attached to the nail is recorded. Each nail is tested individually.

Which nail becomes the strongest permanent magnet?

|  | number of paper clips attached to the nail |  |
|---|---|---|
|  | bar magnet present | bar magnet removed |
| **A** | 2 | 0 |
| **B** | 2 | 1 |
| **C** | 4 | 3 |
| **D** | 5 | 2 |

> [!answer]- Ответ
> **C**
