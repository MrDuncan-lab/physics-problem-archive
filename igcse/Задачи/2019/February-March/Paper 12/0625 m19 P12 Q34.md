> [!abstract] Кратко (составлено моделью)
> Выбрать необходимое оборудование для демонстрации электромагнитной индукции с магнитом и проводами.

A student wishes to demonstrate electromagnetic induction.

He has a magnet and connecting wires.

Which other apparatus does he need?

|  | voltmeter | battery |
|---|---|---|
| **A** | ✓ | ✓ |
| **B** | ✓ | ✗ |
| **C** | ✗ | ✓ |
| **D** | ✗ | ✗ |

key: ✓ = needed, ✗ = not needed

> [!answer]- Ответ
> **B**

> [!report]- Отчёт экзаменаторов
> Most candidates incorrectly assumed that a battery is needed to induce an electromotive force (e.m.f.). However, stronger candidates recognised the basic concept that background count rate needs to be subtracted from the recorded count rate in order to find the count rate due to the course.
