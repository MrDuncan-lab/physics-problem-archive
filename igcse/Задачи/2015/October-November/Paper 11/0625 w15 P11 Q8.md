> [!abstract] Кратко (составлено моделью)
> Определение работы по силе и перемещению.

What needs to be known to calculate the work done by a force acting on an object?

|  | the size of the force | the distance the force moves the object | the time for which the force acts |
|---|---|---|---|
| **A** | ✓ | ✓ | ✓ |
| **B** | ✓ | ✓ | ✗ |
| **C** | ✓ | ✗ | ✓ |
| **D** | ✓ | ✗ | ✗ |

key: ✓ = needed, ✗ = not needed

> [!answer]- Ответ
> **B**

> [!report]- Отчёт экзаменаторов
> Although able candidates scored very highly in this question on work, weaker candidates believed that the time for which a force acts was required to calculate work, possibly confusing it with power.
