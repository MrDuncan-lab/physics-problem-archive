> Вычисление периода полураспада по графику активности.

Fig. 11.1 shows how the count rate from a radioactive source varies with time.

![[0625-m15-22-p16-f1.svg]]

**Fig. 11.1**

**(a)** Using Fig. 11.1, describe how the count rate changes with time. **[2]**

**(b)** **(i)** Using Fig. 11.1, determine how many seconds it takes for the count rate to change from 60 counts / s to 15 counts / s.

number of seconds =  \_\_\_\_\_\_ **[1]**

**(ii)** State the number of half-lives in this time.

number of half-lives =  \_\_\_\_\_\_ **[1]**

**(c)** Calculate the half-life of the radioactive substance.

half-life =  \_\_\_\_\_\_ s **[2]**

**(d)** State the time taken for the count rate to change from 10 counts / s to 5 counts / s.

time =  \_\_\_\_\_\_ s **[1]**

**Question 12 is on the next page.**

> [!answer]- Ответ (итоговые ответы из схемы оценивания)
> **(c)** 53 OR 53.5 (s) ecf (b)(i)
