> Изменение работы и мощности при поднятии более лёгких блоков.

A labourer on a building site lifts heavy concrete blocks onto a lorry. Lighter blocks are now lifted the same distance in the same time.

What happens to the work done in lifting each block and the power exerted by the labourer?

|  | work done in lifting each block | power exerted by labourer |
|---|---|---|
| **A** | decreases | decreases |
| **B** | decreases | remains the same |
| **C** | increases | increases |
| **D** | remains the same | increases |
