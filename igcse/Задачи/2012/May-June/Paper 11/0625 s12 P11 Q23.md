> [!abstract] Кратко (составлено моделью)
> Виртуальность и зеркальная симметрия изображения плоского зеркала.

The image formed by a plane mirror is upright.

![[0625-s12-11-p10-f1.svg]]

What are the other characteristics of the image?

|  | laterally inverted (left to right) | magnified (larger than the object) |  |  | virtual |
|---|---|---|---|---|---|
| A | no | yes |  |  | yes |
| B | yes | no |  |  | no |
| C | yes | no |  |  | yes |
| D | yes | yes |  |  | no |
|  |  |  | yes |  |  |
| A student draws three rays of light from point P through a converging lens. |  |  |  |  |  |

> [!answer]- Ответ
> **C**

> [!report]- Отчёт экзаменаторов
> This question concerned the image formed by a plane mirror. A large majority of candidates were familiar with the fact that the image is laterally inverted and not magnified, but some of these did not appreciate that it is also virtual.
