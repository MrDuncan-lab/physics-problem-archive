# Question 11 (7 marks)

> [!abstract] Кратко (составлено моделью)
> Заряды массы частиц и состав нейтрального атома урана.

**(a)** The charges on the particles in an atom may be represented by

0 or +1 or –1.

The masses of the particles in an atom may be represented by

0 or *m* or 2000 *m*.

Using these choices, complete the table below.

| particle | charge | mass |
|---|---|---|
| electron | –1 | *m* |
| neutron |  |  |
| proton |  |  |

**[4]**

**(b)** How many of each of these particles are there in a neutral atom of$^{238}_{92}$U?

number of electrons =  \_\_\_\_\_\_

number of neutrons =  \_\_\_\_\_\_

number of protons =  \_\_\_\_\_\_ **[3]**

> [!grading]- Схема оценивания (mark scheme)
> | Пункт | Ответ | Баллы |
> |---|---|---|
> | (a) | neutron 0 2000 m | B2 |
> |  | proton +1 2000 m | B2 |
> | (b) | 92 | B1 |
> |  | 146 | B1 |
> |  | 92 no e.c.f. | B1 |

> [!report]- Отчёт экзаменаторов
> This question was well answered by more able candidates.
>
> **(a)** There were very few candidates that were able to complete correctly the table, a common misconception being that a neutron has no mass.
>
> **(b)** There were very few candidates who were able to correctly identify the number of particles in the atom. Despite making responses, a significant number of candidates did not score any marks for this question.
