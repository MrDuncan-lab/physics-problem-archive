> [!abstract] Кратко (составлено моделью)
> Заполнить таблицу истинности логического элемента NAND.

An incomplete truth table for a NAND gate is shown.

| input P | input Q | output |
|---|---|---|
| 0 | 0 | W |
| 0 | 1 | X |
| 1 | 0 | Y |
| 1 | 1 | Z |

What are the values of W, X, Y and Z?

|  | W | X | Y | Z |
|---|---|---|---|---|
| **A** | 0 | 0 | 0 | 1 |
| **B** | 0 | 1 | 1 | 1 |
| **C** | 1 | 0 | 0 | 0 |
| **D** | 1 | 1 | 1 | 0 |

> [!answer]- Ответ
> **D**
