> [!abstract] Кратко (составлено моделью)
> Определить удлинение пружины при разных нагрузках по измеренным длинам.

A student conducts an experiment by hanging different loads on a spring. The diagrams show the lengths of the spring with different loads.

![[0625-w17-11-p5-f1.svg]]

Which row gives the correct extensions of the spring?

|  | extension / cm |  |  |
|---|---|---|---|
|  | 0 N | 2.0 N | 4.0 N |
| **A** | 0 | 3.0 | 3.0 |
| **B** | 0 | 3.0 | 6.0 |
| **C** | 3.0 | 3.0 | 3.0 |
| **D** | 3.0 | 6.0 | 9.0 |

> [!answer]- Ответ
> **B**

> [!report]- Отчёт экзаменаторов
> There was often confusion between the terms “length of a spring” and “extension of the spring”.
