> Выбрать ядерное уравнение бета-распада полония в астат.

Polonium, Po, has a proton number equal to 84 and a nucleon number equal to 218.

Polonium changes into astatine, At, by emitting a β-particle.

Which equation represents this decay?

**A** Po → At + β

84 85 –1

218 218 0

**B** Po + β → At

84 –1 85

218 0 218

**C** Po → At + β

218 218 0

84 85 –1

**D** Po + β → At

218 0 218

84 –1 85

> [!answer]- Ответ
> **C**
