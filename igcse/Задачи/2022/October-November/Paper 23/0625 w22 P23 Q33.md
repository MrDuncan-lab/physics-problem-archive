> Определить логические состояния системы предупреждения холодильника по показаниям датчиков и выключателя.

The diagram shows how logic gates can be used to monitor the temperature in a refrigerator.

![[0625-w22-23-p15-f1.svg]]

The warning light will come on if the output at Z is 1.

The door R is open, the temperature sensor S is cold and the main system switch T is on.

What is the logic state at Y and what is the state of the warning light?

|  | logic state at Y | warning light |
|---|---|---|
| **A** | 0 | off |
| **B** | 0 | on |
| **C** | 1 | off |
| **D** | 1 | on |

> [!answer]- Ответ
> **D**
