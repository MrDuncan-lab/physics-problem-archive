> [!abstract] Кратко (составлено моделью)
> Соотнести области электромагнитного спектра с применениями и характерными длинами волн.

The diagram shows the electromagnetic spectrum. The numbers indicate the approximate

wavelength at the boundaries between the various regions of the spectrum.

For a device to be able to make use of electromagnetic radiation, it needs an aerial of approximately the same size as the wavelength of the radiation it is designed to work with.

| P | Q | R | S |  | T |  | U | V |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  | S |  |  |  |  |
| 1 m 10$^{\text{–3}}$ m 7 × 10$^{\text{–7}}$ m Which statement is correct? |  |  |  | 4 × 10$^{\text{–7}}$ m |  | 10$^{\text{–8}}$ m 10$^{\text{–11}}$ m |  |  |

**A** A mobile phone uses radiation from region P.  
**B** A television satellite dish uses radiation from region Q.  
**C** The receptor cells in an eye use radiation from region R.  
**D** The remote controller for a television uses radiation from region U.

> [!answer]- Ответ
> **B**

> [!report]- Отчёт экзаменаторов
> The key to this question was to know the regions of the electromagnetic spectrum in order, and so to identify S as visible light. A further clue was provided by it being the only region with a very narrow range of wavelengths. A common misconception was to suppose that mobile phones use radio waves rather than the microwaves that are explicitly stated in section 3.3 of the syllabus.
