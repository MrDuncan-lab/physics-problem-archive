> Определить свойства жидкости по сохранению формы и сжимаемости.

Which properties does a liquid have?

|  | definite shape | can be compressed easily |
|---|---|---|
| **A** | ✓ | ✓ |
| **B** | ✓ | ✗ |
| **C** | ✗ | ✓ |
| **D** | ✗ | ✗ |

key: ✓ = has this property, ✗ = does not have this property

> [!answer]- Ответ
> **D**
