> Усреднение времени при экспериментальном измерении скорости звука.

In an experiment to measure the speed of sound, a student uses a stopwatch to find how long a

sound takes to travel from X to Y. She does this six times.

![[0625-w08-1-p14-f1.svg]]

The table shows her results.

|  | time / s |
|---|---|
| first | 0.5 |
| second | 0.7 |
| third | 0.6 |
| fourth | 0.4 |
| fifth | 0.9 |
| sixth | 0.5 |

What value for the time should be used to calculate the speed of sound?

**A** 0.4 s  
**B** 0.5 s  
**C** 0.6 s  
**D** 0.9 s

> [!answer]- Ответ
> **C**
