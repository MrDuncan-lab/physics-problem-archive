# Question 25 (1 mark)

Источник: [[_pdf/2025/0625_m25_qp_12.pdf#page=10|условие, стр. 10]] · [[_pdf/2025/0625_m25_ms_12.pdf|схема оценивания]] · [[_pdf/2025/0625_m25_er.pdf#page=1|отчёт экзаменаторов]]

> [!abstract] Кратко (составлено моделью)
> Определение типа и размера изображения в плоском зеркале.

Which row describes the image viewed in a plane mirror?

|  | type of image | image size |
|---|---|---|
| **A** | real | enlarged |
| **B** | real | same size |
| **C** | virtual | enlarged |
| **D** | virtual | same size |

> [!answer]- Ответ
> **D**

> [!report]- Отчёт экзаменаторов
> This question assessed candidates’ knowledge of the image formed in a plane mirror. Most candidates knew that the image was the same size as the object but had the misconception that the image was real, so chose option **B**.
