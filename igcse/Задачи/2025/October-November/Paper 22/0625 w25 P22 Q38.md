> Упорядочивание значений гравитационного поля по приближению к планете.

A space probe measures the gravitational field strength at four different distances from a planet.

The point furthest from the planet is measured first and the point nearest the planet is measured last.

In which order were the measurements taken?

**A** 6.3 N / kg, 10 N / kg, 14 N / kg, 20 N / kg  
**B** 10 N / kg, 14 N / kg, 6.3 N / kg, 20 N / kg  
**C** 20 N / kg, 14 N / kg, 6.3 N / kg, 10 N / kg  
**D** 20 N / kg, 14 N / kg, 10 N / kg, 6.3 N / kg

> [!answer]- Ответ
> **A**
