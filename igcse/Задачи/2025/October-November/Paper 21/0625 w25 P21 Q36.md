> Выбор радиоизотопа для облучения пищевых продуктов по периоду полураспада и виду излучения.

Which properties must a radioisotope have for its radiation to make it suitable to kill bacteria

in food?

|  | half-life | type of radiation emitted |
|---|---|---|
| **A** | less than one minute | γ only |
| **B** | several hours | α only |
| **C** | several hours | γ only |
| **D** | several thousand years | α only |

> [!answer]- Ответ
> **C**
