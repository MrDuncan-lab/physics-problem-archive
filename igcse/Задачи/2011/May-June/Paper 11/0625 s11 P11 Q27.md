An ammeter and an 18 Ω resistor are connected in series with a battery. The reading on the

ammeter is 0.50 A. The resistance of the battery and the ammeter can be ignored.

| A 18 Ω |  |  |  |  |  |
|---|---|---|---|---|---|
|  | A Ω |  |  |  |  |
|  |  | Ω |  |  |  |
|  |  | 18 |  |  |  |

What is the electromotive force (e.m.f.) of the battery?

**A** 9.0 N  
**B** 9.0 V  
**C** 36 N  
**D** 36 V

> [!answer]- Ответ
> **B**
