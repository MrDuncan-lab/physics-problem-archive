**IGCSE 0625 Physics** · May/June 2018 · Paper 1 — Multiple Choice (Core), вариант 3 · вопрос 9

> [!abstract] Кратко (составлено моделью)
> Определить сочетание силы и пути, удваивающее выполненную работу.

A student does work by pulling a box across a horizontal floor.

She now pulls a second box along the same floor.

Which row indicates that the student is now doing twice as much work?

|  | force used to pull box | distance the box is pulled |
|---|---|---|
| **A** | is doubled | is doubled |
| **B** | is doubled | is halved |
| **C** | stays the same | is doubled |
| **D** | stays the same | is halved |

> [!answer]- Ответ
> **C**
