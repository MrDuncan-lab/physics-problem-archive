**(ii)** An electromagnetic wave has a wavelength of 1.0 × 10$^{-9}$ m. Use Fig. 7.1 to identify the type of electromagnetic wave. **[1]**

**(b)** All electromagnetic waves travel at the same speed in a vacuum.

State one other property that is the same for all electromagnetic waves. **[1]**

**(c)** For each purpose, state one type of electromagnetic radiation that can be used.

**(i)** remote controllers for televisions **[1]**

**(ii)** killing bacterial cells **[1]**
