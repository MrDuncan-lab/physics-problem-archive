The results are shown below.

| load / N | 0 | 1.0 | 2.0 | 3.0 |
|---|---|---|---|---|
| length / cm | 15.2 | 16.2 |  | 18.6 |
| extension / cm | 0 | 1.0 | 2.1 | 3.4 |

Which figure is missing from the table?

**A** 17.2  
**B** 17.3  
**C** 17.4  
**D** 17.6
