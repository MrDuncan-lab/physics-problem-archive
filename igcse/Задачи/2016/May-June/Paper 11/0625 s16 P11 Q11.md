> Сравнение мощности детей при подъёме по лестнице.

Four different children run up the same set of stairs.

For which child is the useful power to climb the stairs the greatest?

|  | mass of child / kg | time taken / s |
|---|---|---|
| A | 40 | 15 |
| B | 50 | 25 |
| C | 60 | 25 |
| D | 70 | 15 |

> [!answer]- Ответ
> **D**
