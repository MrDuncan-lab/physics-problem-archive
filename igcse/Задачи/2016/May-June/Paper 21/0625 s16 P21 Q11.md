A force acts on an object and causes the object to move a certain distance, in the same direction

as the force.

Which row represents a situation in which the largest amount of work is done on the object by the force?

|  | force / N | distance moved / m |
|---|---|---|
| A | 2.0 | 40.0 |
| B | 10.0 | 2.0 |
| C | 20.0 | 6.0 |
| D | 100.0 | 1.0 |
