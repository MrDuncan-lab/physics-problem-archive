> [!abstract] Кратко (составлено моделью)
> Определить, какая характеристика тела изменяется при движении по окружности с постоянной скоростью.

An object travels in a circular path at constant speed.

Which statement about the object is correct?

**A** It has changing kinetic energy.  
**B** It has changing momentum.  
**C** It has constant velocity.  
**D** It is not accelerating.

> [!answer]- Ответ
> **B**

> [!report]- Отчёт экзаменаторов
> Circular motion proved a challenging topic for many candidates, with many believing that there was no acceleration.
