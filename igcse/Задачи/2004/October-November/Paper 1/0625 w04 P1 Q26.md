> [!abstract] Кратко (составлено моделью)
> Проверка взаимодействий магнитов и немагнитных материалов.

A student carries out four tests with a magnet.

Which result shown is not correct?

|  | arrangement | result |
|---|---|---|
| **A** | S magnet N iron bar | attracts |
| **B** | S magnet N S magnet N | attracts |
| **C** | N magnet S copper bar | no effect |
| **D** | N magnet S N magnet S | repels |

> [!answer]- Ответ
> **D**
