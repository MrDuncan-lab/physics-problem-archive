> Чем действительное изображение отличается от мнимого

The image formed by a lens can be described as real or virtual.

Which row of the table describes a real image and a virtual image?

|  | **Real image** | **Virtual image** |
|---|---|---|
| **A** | Formed on the same side of the lens as the object | Formed on the same side of the lens as the object |
| **B** | Can be produced on a screen | Formed on the same side of the lens as the object |
| **C** | Formed on the same side of the lens as the object | Can be produced on a screen |
| **D** | Can be produced on a screen | Can be produced on a screen |

> [!answer]- Ответ
> **B**
