> [!abstract] Кратко (составлено моделью)
> Показания приборов при замене элемента на элемент с большим внутренним сопротивлением

The circuit shown contains a cell with internal resistance.

![[8PH0-jun24-1-p4-f1.svg]]

The cell is replaced with another cell, with the same e.m.f. but greater internal resistance.

Which row of the table shows what happens to the ammeter reading and voltmeter reading?

|  | **Ammeter reading** | **Voltmeter reading** |
|---|---|---|
| **A** | increases | increases |
| **B** | increases | decreases |
| **C** | decreases | increases |
| **D** | decreases | decreases |

> [!answer]- Ответ
> **D**

> | Пункт | Ответ (acceptable answers) | Указания (additional guidance) | Баллы |
> |---|---|---|---|
> |  | **The only correct answer is D ammeter reading decreases and voltmeter decreases**<br>**A** *is not correct because the overall resistance of the circuit is increasing, so the current must decrease.*<br>**B** *is not correct because the overall resistance of the circuit is increasing, so the current must decrease.*<br>**C** *is not correct because the current decreases, but as V=IR this would not increase the voltmeter reading* |  | 1 |
