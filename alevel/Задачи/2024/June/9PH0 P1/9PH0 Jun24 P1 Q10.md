> Какая формула не годится для максимальной высоты брошенного тела

An object was thrown so that it followed the path shown. Assume drag forces were negligible.

![[9PH0-jun24-1-p5-f2.svg]]

The object was thrown with an initial vertical component of velocity *u*. The time taken to reach maximum height is *t*.

Which of the following could **not** be used to determine the maximum vertical height *s* reached by the object?

**A** *s* = *ut* – $\dfrac{1}{2}$ *gt*$^{2}$  
**B** *s* = *ut*  
**C** *s* = $\dfrac{1}{2}$ *ut*  
**D** *s* = $\dfrac{u^{2}}{2g}$

> [!answer]- Ответ
> **B**
