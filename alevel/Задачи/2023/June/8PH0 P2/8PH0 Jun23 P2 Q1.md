> Единицы величин n и d в формуле дифракционной решётки

The wavelength of light emitted from a laser can be determined using a diffraction grating. The equation used to calculate the wavelength is

*nλ* = *d* sin *θ*

Which row of the table shows possible units for *n* and *d*?

|  | ***n*** | ***d*** |
|---|---|---|
| **A** | no unit | mm$^{-1}$ |
| **B** | no unit | mm |
| **C** | mm | no unit |
| **D** | mm$^{-1}$ | no unit |

> [!answer]- Ответ
> **B**
