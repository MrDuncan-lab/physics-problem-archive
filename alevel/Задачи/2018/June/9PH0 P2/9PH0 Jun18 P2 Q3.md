> Какие оси графика дают жёсткость образца как угловой коэффициент

A deforming force is applied to a sample of material.

Which row of the table shows the axes of a graph for which the gradient is stiffness *k*?

|  | ***y*-axis** | ***x*-axis** |
|---|---|---|
| **A** | extension | force |
| **B** | force | length |
| **C** | stress | strain |
| **D** | strain | length |

> [!answer]- Ответ
> **B**

> [!grading]- Схема оценивания (mark scheme)
> | Пункт | Ответ (acceptable answers) | Указания (additional guidance) | Баллы |
> |---|---|---|---|
> |  | The only correct answer is **B** because the gradient of this graph is change in length ÷ change in force and the change<br>in length is the same as the change in extension, so the gradient is equal to stiffness<br>A is not correct because a graph of extension against force will have a gradient of 1/*k*<br>C is not correct because a graph of stress against strain will have a gradient equal to the Young modulus for the<br>sample<br>D is not correct because a graph of strain versus length is equivalent to a graph of extension versus (length)$^{2}$, so it<br>does not have a gradient equal to *k* |  | 1 |
