> [!abstract] Кратко (составлено моделью)
> Действующее значение переменного тока по амплитуде 3 А

A wire carries an alternating current of peak value 3 A.

Which of the following is the root-mean-square value of this current?

**A** 1.5 A  
**B** 2.1 A  
**C** 4.2 A  
**D** 9.0 A

> [!answer]- Ответ
> **B**

> |---|---|---|---|
> |  | **The only correct answer is B**<br>A *is not correct because it is 3 divided by 2*<br>C *is not correct because it is 3 x root 2*<br>D *is not correct because it is 3*$^{2}$ | 2.1 A | 1 |
