The photograph shows a guitar. The strings of the guitar are at the same tension.

![[8PH0-jun19-2-p10-f6.png]]

When a string is plucked, a standing wave is set up on the string.

\* **(a)** Explain how a standing wave is set up on a string. **[6]**

**(b)** A thicker string produces a note with a lower fundamental frequency than a thinner string of the same material.

Justify this statement. **[5]**
