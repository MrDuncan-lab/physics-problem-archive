> [!abstract] Кратко (составлено моделью)
> Соотношение скоростей и показателей преломления при полном внутреннем отражении

A ray of light travels through medium 1 of refractive index $n_{1}$ and is incident at an interface with medium 2 of refractive index $n_{2}$. The ray is totally internally reflected at the interface.

![[8PH0-jun19-2-p4-f2.svg]]

speed of the light in medium 1 = $v_{1}$

speed of the light in medium 2 = $v_{2}$

Which row of the table is correct for this situation?

|  |  |  |
|---|---|---|
| **A** | $v_{1} > v_{2}$ | $n_{1} > n_{2}$ |
| **B** | $v_{1} < v_{2}$ | $n_{1} > n_{2}$ |
| **C** | $v_{1} > v_{2}$ | $n_{1} < n_{2}$ |
| **D** | $v_{1} < v_{2}$ | $n_{1} < n_{2}$ |

> [!answer]- Ответ
> **B**
