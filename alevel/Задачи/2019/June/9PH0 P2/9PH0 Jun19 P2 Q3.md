> Изменение энергии связи на нуклон при делении и синтезе

In both nuclear fission and nuclear fusion there are changes in the binding energy per nucleon. This releases energy.

Which row of the table correctly shows the change in binding energy per nucleon for both processes?

|  | **Nuclear fission** | **Nuclear fusion** |
|---|---|---|
| **A** | decrease | decrease |
| **B** | decrease | increase |
| **C** | increase | decrease |
| **D** | increase | increase |

> [!answer]- Ответ
> **D**
