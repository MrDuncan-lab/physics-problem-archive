> Тип волн в гитарной струне и в звуке

Sound waves are produced by a vibrating guitar string.

Which row in the table correctly describes the waves produced?

|  | **Guitar string** | **Sound** |
|---|---|---|
| **A** | transverse | transverse |
| **B** | longitudinal | longitudinal |
| **C** | longitudinal | transverse |
| **D** | transverse | longitudinal |
