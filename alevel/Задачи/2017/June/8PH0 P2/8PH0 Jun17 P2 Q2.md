> Какие переменные дают прямую для скорости волны в натянутой струне

The velocity of a wave on a string is given by $v = \sqrt{\dfrac{T}{\mu}}$ where *T* is the tension in the string and *μ* is a constant.

Which of the following pairs of variables, if plotted, would produce a straight line graph?

|  | ***x*****-axis** | ***y*****-axis** |
|---|---|---|
| **A** | *T* | $\sqrt{v}$ |
| **B** | *v* | *T* |
| **C** | $\dfrac{1}{v}$ | *T* |
| **D** | $\sqrt{T}$ | *v* |

> [!answer]- Ответ
> **D**
