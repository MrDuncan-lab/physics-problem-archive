# Задача 4. Уравновесим.

**RusPhO 2017** · Муниципальный этап · теория · 8 класс · задача 8-4  
Источник: [[_pdf/RusPhO/2017-municipal.pdf#page=2|условие, стр. 2–3]] · [[_pdf/RusPhO/2017-municipal.pdf#page=13|решение, стр. 13]]

Темы: [[1.10 Статика]]

> [!abstract] Кратко (составлено моделью)
> Найти массу однородного рычага и силу давления груза на него в равновесной системе с нитью и блоком.

К легкой нити, перекинутой через блок, с одной стороны прикреплен однородный рычаг, а с другой - груз, касающийся рычага и имеющий массу $m = 6$ кг. Определите, при какой массе рычага $M$ система останется в равновесии? С какой силой при этом груз будет давить на рычаг? Трения в оси блока нет. Все необходимые расстояния можно взять из рисунка. $g = 10\ \text{м/с}^2$.

![[ruspho-2017-municipal-theory-p2-f2.svg]]

> [!answer]- Ответ
> $M = m/3 = 2\ \text{кг}$,
>
> $N = mg/3 = 20\ \text{Н}$.

> [!solution]- Решение
> **Возможное решение (Замятнин М.)** Расставим силы на груз и рычаг и запишем правило моментов для рычага относительно точки крепления нити:
>
> ![[ruspho-2017-municipal-theory-p13-f2.svg]]
>
> $Nl = Mgl$, где $l$ – длина одной шестой части рычага.
>
> Запишем условия равновесия:
>
> $T + N = mg$ – для груза
>
> $T = Mg + N$ – для рычага.
>
> Решая систему уравнений, получаем:
>
> $M = m/3 = 2\ \text{кг}$,
>
> $N = mg/3 = 20\ \text{Н}$.
