# Задание 7.2. Скатывание шарика.

**RusPhO 2019** · Региональный этап · эксперимент · 7 класс · задача 7-2  
Источник: [[_pdf/RusPhO/2019-region-exp.pdf#page=2|условие, стр. 2]] · [[_pdf/RusPhO/2019-region-exp.pdf#page=3|решение, стр. 3]] · [[_pdf/RusPhO/2019-region-exp.pdf#page=4|критерии, стр. 4]]

Темы: [[7 Эксперименты]], [[1.2 Равноускоренное прямолинейное движение]], [[1.7 Качение твёрдого тела]]

> [!abstract] Кратко (составлено моделью)
> По временам скатывания шарика с разных отметок и графику средней скорости определить скорость после первых пяти сантиметров движения.

На наклонном жёлобе (алюминиевый уголок), начиная от его нижнего конца, фломастером нанесены отметки $N_i$ через каждые 15 см. На 5 см ниже каждой из этих отметок нанесены другие отметки $n_i$. Нижний конец желоба должен касаться упора (деревянного бруска).

Запустите без начальной скорости металлический шарик от отметки $N_i$ и включите секундомер в тот момент, когда шарик прокатывается мимо отметки $n_i$. Остановите секундомер в момент соприкосновения шарика с упором. Повторите эксперимент для каждой из отметок $N_i$ не менее 5 раз. Усредните результат. Заполните таблицу.

![[ruspho-2019-region-experiment-p2-f1.png]]

| $L$, см | | | | | | |
|---|---|---|---|---|---|---|
| $t_1$, с | | | | | | |
| $t_2$, с | | | | | | |
| $t_3$, с | | | | | | |
| $t_4$, с | | | | | | |
| $t_5$, с | | | | | | |
| $t_\text{ср.}$, с | | | | | | |
| $\upsilon_\text{ср}$, см/с | | | | | | |

Постройте график зависимости $\upsilon_{\text{ср.}i}$ от $t_{\text{ср.}i}$.

Определите скорость, которую достигает шарик, преодолев из состояния покоя участок длиной 5 см.

**Оборудование:** Алюминиевый уголок, шарик, закреплённый одним концом в коробке; деревянный брусок (упор); секундомер; миллиметровая бумага формата (А5) для построения графика.

> [!answer]- Ответ
> **4**
>
> $$
> \upsilon(5)\approx17\ \text{см/с}.
> $$

> [!solution]- Решение
> **Возможное решение.**
>
> **1.** Запускаем шарик от самой дальней отметки $N_1$. Измеряем время $t_1$ скатывания. Повторяем эксперимент 5 раз. Вычисляем $t_{\text{ср.}1}$. Заносим результаты в таблицу.
>
> **2.** Аналогично пункту (1) проводим аналогичный эксперимент для других отметок $N_i$.
>
> | $L$, см | 85 | 70 | 55 | 40 | 25 | 10 |
> |---|---|---|---|---|---|---|
> | $t_1$, с | 2,59 | … | … | … | … | … |
> | $t_2$, с | 2,50 | … | … | … | … | … |
> | $t_3$, с | 2,60 | … | … | … | … | … |
> | $t_4$, с | 2,56 | … | … | … | … | … |
> | $t_5$, с | 2,60 | … | … | … | … | … |
> | $t_{\text{ср.}}$, с | 2,57 | 2,25 | 1,91 | 1,51 | 1,08 | 0,51 |
> | $\upsilon_{\text{ср}}$, см/с | 33 | 31 | 29 | 26 | 23 | 20 |
>
> **3.** Строим график $\upsilon_{\text{ср.}i}$ от $t_i$.
>
> ![[ruspho-2019-region-experiment-p3-f1.png]]
>
> **4.** Определяем скорость, которую достигает шарик, преодолев из состояния покоя участок длиной 5 см (момент времени $t=0$ с):
>
> $$
> \upsilon(5)\approx17\ \text{см/с}.
> $$
