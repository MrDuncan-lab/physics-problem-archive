# 8.3 Нелинейная мощность

**RusPhO 2018** · Олимпиада Максвелла · теория · 8 класс · задача 8-3  
Источник: [[_pdf/RusPhO/2018-maxwell-theor.pdf#page=10|условие, стр. 10]] · [[_pdf/RusPhO/2018-maxwell-theor.pdf#page=14|решение, стр. 14–15]]

Темы: [[2.1 Уравнение теплового баланса. 8-ой класс]]

> [!abstract] Кратко (составлено моделью)
> По нелинейной тепловой характеристике определить стационарные потоки через разные последовательные соединения тепловодов и температуру их стыка.

Экспериментатор Глюк создал в своей лаборатории уникальный $Z$-тепловод, зависимость мощности теплового потока $P$ через который от разности температур $\Delta t$ на его концах приведена на рисунке. Для сравнения, на том же графике приведена зависимость мощности теплового потока через обычный $N$-тепловод.

Если два термостата с постоянными температурами $t_1=0\ {}^\circ\text{C}$ и $t_2=100\ {}^\circ\text{C}$ соединить $N$-тепловодом, то по нему пойдет тепловой поток мощностью $P_1=100\ \text{Вт}$.

Определите мощность теплового потока:

**1.** $P_2$ через два $N$-тепловода, соединенные последовательно.

**2.** $P_3$ между термостатами через $Z$-тепловод.

**3.** $P_4$ через два $Z$-тепловода, соединенные последовательно.

**4.** $P_5$ через $Z$ и $N$-тепловоды, соединенные последовательно. Какая в этом случае может быть температура в месте соединения тепловодов друг с другом?

![[ruspho-2018-maxwell-theory-p10-f1.svg]]

> [!answer]- Ответ
> **2** — Из графика $P_3=94$ Вт.
>
> **1** — $P_2=50$ Вт,
>
> **3** — $P_4=67$ Вт,
>
> **4** — $P_5=60$ Вт.
>
> **4** — температура на стыке равна $t=40\ {}^\circ\text{C}$. Если он соединен со вторым термостатом, то
>
> **4** — температура на стыке равна $t=60\ {}^\circ\text{C}$.

> [!solution]- Решение
> # Задача 8.3
>
> **1)** Восстановим масштаб по оси мощности на графике. При разности температур $t_1-t_2=100\ {}^\circ\text{C}$ мощность теплового потока через $N$-тепловод равна $P_1=100$ Вт. На графике это значение соответствует сотому делению, следовательно, цена деления равна 1 Вт.
>
> **2)** Теперь по графику находим мощность потока $P_3$ через $Z$-тепловод при разности температур $100\ {}^\circ\text{C}$.
> Из графика $P_3=94$ Вт.
>
> **3)** Рассмотрим случай, когда между термостатами находятся два тепловода, соединенных последовательно. В установившемся режиме мощности теплового потока через тепловоды равны, а разность температур между термостатами равна сумме разностей температур на каждом тепловоде. Получим график $P(\Delta t)$ для последовательного соединения тепловодов, складывая разности температур при одинаковой мощности. Проделаем это для соединений $N+N$, $Z+Z$, $Z+N$ и найдем мощности $P_2$, $P_4$, $P_5$.
>
> ![[ruspho-2018-maxwell-theory-p14-c0859.png]]
>
> Из графика:
> $P_2=50$ Вт,
> $P_4=67$ Вт,
> $P_5=60$ Вт.
>
> Найдем температуры на стыке между тепловодами. При мощности $P_5=60$ Вт разность температур на $Z$-тепловоде равна $40\ {}^\circ\text{C}$ (точка $A$). Если $Z$-тепловод соединен с первым термостатом, то
> температура на стыке равна $t=40\ {}^\circ\text{C}$. Если он соединен со вторым термостатом, то
> температура на стыке равна $t=60\ {}^\circ\text{C}$.
