# Задача 3. Средняя мощность. (Замятнин М.)

**RusPhO 2015** · Муниципальный этап · теория · 8 класс · задача 8-3  
Источник: [[_pdf/RusPhO/2015-municipal.pdf#page=3|условие, стр. 3]] · [[_pdf/RusPhO/2015-municipal.pdf#page=3|решение, стр. 3]] · [[_pdf/RusPhO/2015-municipal.pdf#page=4|критерии, стр. 4]]

Темы: [[2.1 Уравнение теплового баланса. 8-ой класс]]

> [!abstract] Кратко (составлено моделью)
> По времени последовательного нагрева воды двумя нагревателями определить мощность одного нагревателя для большего изменения температуры за то же время.

Бак с водой нагрели сначала на $\Delta t$ с помощью нагревателя, имеющего мощность $N_1 = 300\ \text{Вт}$, а затем ещё на $2\Delta t$ нагревателем с мощностью $N_2 = 400\ \text{Вт}$. На весь нагрев было затрачено время $\tau$. Какую мощность должен иметь нагреватель, с помощью которого за такое же время $\tau$ можно нагреть этот бак на $4\Delta t$? Потерями тепла можно пренебречь.

> [!answer]- Ответ
> $$
> N = \frac{4N_1N_2}{2N_1 + N_2} = 480\ \text{Вт}.
> $$

> [!solution]- Решение
> **Возможное решение**
>
> Пусть для нагревания бака на $\Delta t$ ему требуется сообщить количество теплоты $Q$. Тогда общее время нагрева в первом случае равно: $\tau = \frac{Q}{N_1} + \frac{2Q}{N_2}$. Во втором случае $\tau = \frac{4Q}{N}$. Приравнивая, получаем
>
> $$
> N = \frac{4N_1N_2}{2N_1 + N_2} = 480\ \text{Вт}.
> $$
